# Printable Fusion parts

Only `BedFrame_*` components from `Assembly_Assembled` are exported here. Current pitch-60 set: CellDeck, ServiceDeck, ElectronicsBay, BottomPanel. Units: mm.

Generic valve/screw references are in `../reference/` and are not print parts. Previous STL files, including dowels and BodyNN artifacts, are preserved in `../../_old/2026-11-06_before_revision/stl/`.

Geometry checks do not replace hardware fit, Bambu Studio slicing, support-removal or load/pressure testing. See `../../docs/PRINT_CHECKLIST.md`.
