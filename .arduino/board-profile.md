# Плата и оригинальная карта подключения · 2026-11-16

## Установленная плата и инструменты

- Arduino UNO, ATmega328P-совместимая; USB VID 2341/PID 0043,
  serial 24238313635351910130, последний порт /dev/cu.usbmodem1101.
- FQBN arduino:avr:uno, Arduino CLI 1.5.1, AVR 1.8.8, Servo 1.3.0, логика 5 В.
- Shield KJH: inputs/2026-11-15_upper-shield_reference.png. На сохранённом фото
  видны S/+/- и SW1; конкретная перемычка питания не идентифицирована.
- Исторически показанный адаптер: 5 В DC / 5 А, центр плюс. Это не подтверждает
  соответствие требованию питания многоканального примера или текущее подключение.
- Показанные ключи получают Servo-подобный сигнал по трём проводам, насос
  подключается к двухконтактному выходу ключа. Маркировка/допустимый ток ключа
  не установлены. Оранжевый S, красный +, коричневый − по прежней карте оператора.

## Карта фаз · 2026-11-17

Старая тройка D2–D4 / D6–D8 / D10–D12 снята с подключения. Насосы общие.

| Фаза | Пины | Что |
|---|---|---|
| Надув | D2 D3 D4 | три насоса надува, любой порядок |
| Надув | D6 | клапан надува группы 1 |
| Надув | D7 | клапан надува группы 2 |
| Сдув | D8 D10 D11 | три насоса сдува, любой порядок |
| Сдув | D12 | клапан откачки группы 1 |
| Позже | D9 | клапан откачки группы 2, сейчас пусто |

D5 и D13 не используются. Шилд стоит рядом, не надет. Сигнал и GND общие, 5V шилда на 5V UNO не сажать.

## Питание по документации продавца

- https://www.wnhv.com/zl/huxi/ : внешнее питание **не выше 7.4 В**, иначе
  «сгорят электронные ключи»; при USB **не подключать** внешний БП
  (риск обратного тока в ПК).
- https://www.wnhv.com/huxi/huxi.html : для 4 групп рекомендуют **5 В / 10 А**.
- qiuqiu4zu.ino: раздельное питание плат, снять перемычку на расширителе,
  расширитель **5 В >10 А**.
- Конденсатор на щите «220 16V» — рейтинг детали, **не** рабочий лимит ключей.
- Рабочий ориентир для щита/ключей по тексту продавца: **≤7.4 В**, для
  многоканального режима явно указано **5 В**. Конкретная перемычка и SW1
  на нашем экземпляре не идентифицированы; при стеке щит↔UNO питание общее
  через разъёмы (наблюдалось ранее).
- Обход без найденной перемычки (2026-11-16 вечер): щит рядом, не в стеке.
  Jumpers GND + D8 + D10. USB → UNO, адаптер → jack щита. Фото:
  inputs/2026-11-16_power-isolation_D8-D10-GND.png.
  Цикл qiqiu после Reset: насосы не двигались.
  Гипотеза: jack щита сидит на VIN, ряд `+` ключей — на 5V; без перемычки
  VIN→5V **на щите** ключи без питания. 5V щита на Arduino 5V не вести.
