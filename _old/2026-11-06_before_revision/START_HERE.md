# Bed prototype — start here

**Handoff / полная инструкция:** [README.md](README.md) (в т.ч. для **Codex**).

## Daily workflow

1. Edit **`design/bed_params.json`**
2. Fusion **Design** → Run **`design/fusion/build_bed_frame_environment.py`**
3. Run **`design/fusion/save_and_export.py`** (or MCP) → **`export/stl/`**
4. Save **`BedPrototype_Frame_v1.f3d`** to hub **`bed frame`**

Grid: **3×4**, shallow cell seat, tubes bottom-center — [docs/TUBE_ROUTING.md](docs/TUBE_ROUTING.md).
